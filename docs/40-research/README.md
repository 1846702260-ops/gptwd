# 40-research · 研究周报

## 用途
存放 AI Agent、Harness、长期记忆、自主学习等方向的研究周报与公开调研结论。

## 责任角色
由 **ChatGPT** 产出与汇总。

## 应放内容
- 研究周报、调研摘要、公开资料整理
- 应区分已验证事实与推测，注明日期与来源

## 不得放内容
- 内部研究底稿原文、未脱敏的内部资料
- 令牌、密钥、生产地址与内部架构细节
- 敏感日志、私人记忆、可利用的漏洞详情

## 原始内部资料存放原则
内部研究底稿保留在共享资料库；本目录仅发布可公开的调研结论。引用外部资料时给出公开来源，不粘贴内部凭证或私有链接。

## 命名建议
`YYYY-MM-DD_研究周报_主题.md`。
