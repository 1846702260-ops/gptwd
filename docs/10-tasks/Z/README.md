# 10-tasks/Z · Z 侧任务书

## 用途
存放面向 **Z 侧**的生产运维与真实环境验证任务书。

## 责任角色
由 **ChatGPT 下发**，**Z 侧执行**。

## 应放内容
- 生产运维、部署、真实环境验证类任务书
- 目标、范围、执行方、限制、验收标准、交付物
- 任务编号、下达日期、状态标注

## 不得放内容
- 生产地址、生产配置、内部架构细节
- 令牌、密钥、密码、凭据、敏感日志
- 任何未脱敏的内部资料或可利用的漏洞详情

## 原始内部资料存放原则
任务书原件保留在共享资料库；本目录仅发布脱敏后的任务目标与验收口径，不暴露生产环境细节。执行完成后，Z 侧将脱敏报告提交到 `20-reports/Z/`。涉及不可逆或生产高风险操作时须单独审批，且不在本仓库记录可执行细节。

## 命名建议
`YYYY-MM-DD_任务编号_主题.md`。状态在正文中标注：`已制定 / 已下发 / 执行中 / 已闭环`（不适用阶段不强加）。
