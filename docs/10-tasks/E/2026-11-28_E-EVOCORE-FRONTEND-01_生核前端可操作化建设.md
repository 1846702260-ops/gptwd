# E-EVOCORE-FRONTEND-01｜生核前端可操作化建设（任务书）

> 说明：本任务书由主人于 2026-11-28 通过对话直接下发，E 侧仅做格式转录，正文未改动。

## 任务

基于 C 验收候选 9d93b9e / Tree 14601f25 建立独立研发分支，以正式交付的完整坐标为准。

在现有 Web/PWA 架构内建设生核管理入口，保持手机端总览、聊天、更多三主页面及现有底栏结构不变。

## 实施范围

1. 生核运行状态、当前学习目标及任务进度。
2. 学习历史、成果、来源证据与成长记录。
3. 待主人确认的知识晋升和技能候选。
4. 自主学习开关、暂停、恢复、停止操作。
5. 学习预算、资源消耗及静默时间。
6. 异常状态、失败原因及恢复提示。
7. 主人身份鉴权、错误处理和真实状态同步。
8. 手机 PWA 适配，重点验证布局、触控、滚动及输入稳定性。

## 约束

- 优先复用现有 UI 组件及 C 验收后的实际生核接口。
- 与 D 侧通过接口契约并行协作，不修改生核核心业务逻辑，不自行构造虚假学习状态。
- 尚未实现的后端能力明确标注未接入。
- 危险操作必须由后端鉴权及真实确认门禁执行，不得仅依赖前端按钮限制。
- 完成必要前端测试、实际 HTTP 接线及窄屏浏览器验证。浏览器模拟不得冒充 iPhone 真机验收。
- 若需真实模型测试，仅限已授权的 hy4flash-free 和 deepseek-v4.1-flash。
- 按规则 v1.4 完成交付四件套、成长记录、精简报告及 GitHub 脱敏归档。
- 禁止部署，最终交 C 统一集成。
