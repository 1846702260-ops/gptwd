## M0 实际入口、边界与前置安全
盘点实际现有 Skill/MCP/插件入口、注册表、工具网关、授权/审批/审计、Web/PWA，区分有源码、已接线、实际实测。列出拟修改文件、调用契约和与 K/C/备份路径冲突检查，禁止修改忆核/灵核/心核核心链路与生产 ops；如需触及共享网关或核心编排，先提交最小接口差异由总协调裁决。R 历史线索：工具未鉴权、直接 fetch、插件风险级别失效、聊天链无审计、dryRun 未透传。只在隔离环境用合成主体和本地 mock 复现与 E1 相关路径；历史线索不是现状事实。任何实际绕权、未经批准执行或隐私泄漏阻断该接入路径，不可带病开放；范围内最小修复并验证，不开展泛安全专项。未经授权不访问生产、网络私有地址、真实记忆/凭据。无法取得前置证据则报告 BLOCKED，不编造。

## M1 标准 Skills 适配
依据 Agent Skills 官方规范固定版本与原始来源；支持标准目录、SKILL.md YAML frontmatter（名称、描述、允许的元数据等），发现阶段只读有界元数据，激活后才按需读取正文/资源；复用既有技能实验室/候选状态，不另建注册表或第二套存储。使用成熟安全解析器（已有优先；新增依赖需许可证与版本固定），禁止任意 YAML 对象执行；防路径穿越、符号链接越界、超大文件、恶意归档、重复名称、未知字段和植入提示指令。默认禁用脚本运行、网络、安装钩子，导入不等于授权。最少提供正常标准技能、坏格式、越权资源、恶意正文、重复导入/更新/停用等独立样本；能够展示识别、预览、拒绝原因，不修改核心人格、记忆或权限。保留原生技能兼容，不强迁移历史数据。

## M2 MCP 标准差异补齐
复用既有客户端和可信工具注册网关，按 R 所核实的 2025-06-18/2025-11-25 规范与实际版本协商，明确 Streamable HTTP 中 JSON 与 SSE 响应/会话/断线与错误的契约，不将旧 HTTP+SSE transport 与新机制混淆。先核实现有实现，不机械地增加重复通道。实现本地受控端点 initialize→tools/list→tools/call，按真实身份和注册 schema 检查、风险定级、审批、执行、审计；工具注解与返回均不可信，未知工具/版本漂移拒绝或受控重新注册。按标准核实授权、凭证隔离、日志脱敏和最小作用域；禁止任意 URL/SSRF、重定向泄漏凭证、未经审批的高风险工具、dryRun 实际执行。优先现有客户端/成熟 SDK 的薄适配而非自写全协议栈；缺少 OAuth 服务或真实外部权限时，交付独立模拟证据并清楚标明未验证，不伪造 OAuth 成功。不得把未验证的网络通道默认启用。MCP 扩展若超出当前安全与改动边界，先交可复现缺口及分期建议，保留第一批可交付增量。

## M3 实测与集成准备
本地合成工具/技能完成发现、导入、显式授权、调用、结果、审计、停用/更新的端到端测试；失败关闭、低权限、权限撤回、schema 漂移、超时/中断/重试不重复副作用。涉及模型理解才用主人指定 `hy4flash` 与 `DeepSeek-V4.1-Flash`，先核实际 ID/接口/额度，不能擅自换模型或使用生产私人数据；纯协议测试无需调用模型。Web/PWA 复用既有入口，仅在 E1 验证所必需时补最小状态/按钮；不做大型前端改版或市场。对照现有功能与新标准样本，记录接入成本、依赖增量、调用耗时与不兼容项。不要重复 K/C 的记忆全量回归，只跑直接影响用例。
