# 10-tasks/E · E 侧任务书

## 用途
存放面向 **E 侧**的生态与扩展研发任务书。

## 责任角色
由 **ChatGPT 下发**，**E 侧执行**。

## 应放内容
- 经批准的外部能力适配、技能与工具接入、非核心功能与界面扩展类任务书
- 目标、范围、执行方、限制、验收标准、交付物
- 任务编号、下达日期、状态标注

## 不得放内容
- 六核核心契约改动、第二套记忆真源或运行中枢的建设计划
- 令牌、密钥、生产地址、内部架构细节、敏感日志
- 任何未脱敏的内部资料

## 原始内部资料存放原则
任务书原件保留在共享资料库；本目录发布脱敏版本。E 初期为机动研发侧，收到独立实施任务后在专用分支开发，不得修改 K 在途任务占用的路径或生产环境；无已批准可实施任务时待命。执行完成后，E 侧将脱敏报告提交到 `20-reports/E/`，并保持任务编号一致。

## 命名建议
`YYYY-MM-DD_任务编号_主题.md`。状态在正文中标注：`已制定 / 已下发 / 执行中 / 待 C 验收 / 已闭环`（不适用阶段不强加）。
