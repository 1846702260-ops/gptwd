# 10-tasks/R · R 侧任务书

## 用途
存放面向 **R 侧**的技术研究与隔离实验任务书。

## 责任角色
由 **ChatGPT 裁决后下发**，**R 侧执行**。

## 应放内容
- 前沿技术、外部生态、源码协议分析、对照实验与可复现 PoC 类任务书
- 目标、范围、执行方、限制、验收标准、交付物
- 任务编号、下达日期、状态标注

## 不得放内容
- 未经审查的第三方代码、可执行实验细节
- 令牌、密钥、生产地址、内部架构细节、真实账号与记忆
- 任何未脱敏的内部资料

## 原始内部资料存放原则
任务书原件保留在共享资料库；本目录发布脱敏版本。R 的研究产物不等于正式功能交付，结论交 ChatGPT 裁决，经批准的实施方案交 K（核心）或 E（扩展）。执行完成后，R 侧将脱敏报告提交到 `20-reports/R/`，并保持任务编号一致。

## 命名建议
`YYYY-MM-DD_任务编号_主题.md`。状态在正文中标注：`已制定 / 已下发 / 执行中 / 待裁决 / 已闭环`（不适用阶段不强加）。
