# R-SELFCORE-V1.0-M0-RESEARCH-01｜自核 V1.0 前沿技术研究与架构选型

## 一、任务目标
为知遥 SelfCore 自核建设提供技术研究、成熟方案比较及架构选型依据。自核的目标是让知遥逐步具备可验证的自我状态认知、能力边界感知、自我评估、成长意识及长期身份连续性。不将拟人化表达或模型自述视为真实自我认知，更不宣称具备意识。

## 二、重点研究方向
1. AI Agent 自我模型与能力边界感知。2. 元认知、不确定性评估及自我纠错。3. 自身知识缺口与能力缺口发现。4. 自我评估、任务表现与能力画像。5. 长期身份、人格连续性及成长轨迹。6. 主动目标形成、兴趣发展及行为动机。7. 自我反思与经验迁移。8. 自主成长过程中的安全治理与主人授权。

## 三、外部技术调研
重点研究2025年至今的相关论文、成熟商业产品、活跃开源项目及 Agent Harness 技术，同时允许引用具有基础价值的早期研究。逐项注明原始来源及发布时间、核心技术创新、实际实现机制、项目活跃度及许可证、实验结果与已知局限、对知遥的复用价值、复用/改造/融合/暂缓建议。不得虚构论文、实验数据及项目能力。

## 四、六核协同研究
研究自核与其他五核之间的职责边界：灵核（认知与决策）、忆核（长期记忆及经历证据）、心核（人格、价值及关系连续性）、生核（学习、成长与进化）、行核（实际行动与结果验证）。自核应复用现有能力，不建立第二套人格、长期记忆或自主学习系统。重点研究自我认知如何基于真实运行状态、能力测试、执行回执及成长证据，而不是依赖模型自由生成自我评价。

## 五、方案比较
至少提出两种可行架构方案。比较实现复杂度、资源消耗、可解释性、可信度、安全边界、长期演化能力及现有架构融合成本。具备条件时开展隔离 PoC，验证自我评估准确性、能力缺口发现及虚假能力声明控制。

## 六、协作边界
K 正在开展知遥内部全系统功能资产盘点。R 主要负责外部研究及技术方案，不重复 K 的完整源码审计。研究成果后续与 K 盘点结果交叉融合，由 G 决定正式建设路线。

## 七、约束
不修改正式业务代码，不部署，不修改生产，不恢复历史记忆。真实模型仅允许可核验零费用的 hy4flash-free（响应 hy4-flash-free）及已有授权预算内的 deepseek-v4.1-flash。不具备条件时标记 BLOCKED。

## 八、交付
