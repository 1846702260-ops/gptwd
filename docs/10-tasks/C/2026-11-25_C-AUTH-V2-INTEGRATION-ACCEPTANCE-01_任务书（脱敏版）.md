## G2：真实链路认证、会话与恢复
- 合成账号+真实 HTTP/HTTPS 服务，验证 MFA challenge 前无完整会话、过期/并发/重放/失败次数、服务重启、全部入口（API/WebSocket/SSE/聊天/工具/记忆/旧改密/服务令牌）权限，CSRF/Origin/代理头信任、Cookie、会话换发和撤销、改邮箱/密码和禁用 MFA 的近期重认证。普通用户不可进入主人安全中心。TOTP 种子 AES-GCM 与账户绑定，计数器跨进程原子，备用码单次原子消耗且不泄露。
- Passkey 校验预设 RP ID 与精确 HTTPS origin（端口按实际配置，不从任意 Host 或转发头推导），challenge 一次性/时效/绑定操作、签名、UV required 服务端强校验、凭证归属/userHandle、跨账户、撤销、重认证、并发。兼容同步型 passkey 的合法零计数器行为，不误拒苹果平台；异常回退拒绝按实际标准和凭证类型验证。软件认证器不能替代苹果真机；无真实模型任务，不调用模型。默认关闭 Passkey，真实域名 Safari/主屏 PWA 留 Z 授权验收；记录开关依赖及禁用状态可回退密码/TOTP。
- 离线恢复仅可信本机 CLI + 管理权限 + 独立 256bit 一次性恢复密钥，不能在线跳过第二因素；恢复后 ownerId 不变、会话和凭证撤销、TOTP 需重绑，安全恢复凭证轮换，避免 CLI 参数/日志泄露；无 SMTP 时邮箱仅登录名、不承诺邮箱已验证，不接付费服务。核查原主人首次迁移与忘密、丢验证器、撤销及旧备份回滚的实际路径。
