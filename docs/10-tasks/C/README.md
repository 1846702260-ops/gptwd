# 10-tasks/C · C 侧任务书

## 用途
存放面向 **C 侧**的独立验收、集成，以及既定范围内直接修复类任务书。

## 责任角色
由 **ChatGPT 下发**，**C 侧执行**。

## 应放内容
- 独立验收、集成、范围内直接修复、补测与复验任务书
- 目标、范围、执行方、限制、验收标准、交付物
- 任务编号、下达日期、状态标注

## 不得放内容
- 未下发的草稿、内部讨论
- 令牌、密钥、生产地址、内部架构细节、敏感日志
- 任何未脱敏的内部资料

## 原始内部资料存放原则
任务书原件保留在共享资料库；本目录发布脱敏版本。执行完成后，C 侧将脱敏报告提交到 `20-reports/C/`，必要时更新 `30-journal/` 的《知遥记录》脱敏摘要。不可逆、生产高风险或范围外操作须单独审批，不在任务书范围内自动执行。

## 命名建议
`YYYY-MM-DD_任务编号_主题.md`。状态在正文中标注：`已制定 / 已下发 / 执行中 / 待 Z 复验（如适用） / 已闭环`。
