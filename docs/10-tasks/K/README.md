# 10-tasks/K · K 侧任务书

## 用途
存放面向 **K 侧**的研究与开发任务书。

## 责任角色
由 **ChatGPT 下发**，**K 侧执行**。

## 应放内容
- 研究与开发类任务书（目标、范围、执行方、限制、验收标准、交付物）
- 任务编号、下达日期、状态标注

## 不得放内容
- 未下发的草稿规划、内部讨论
- 令牌、密钥、生产地址、内部架构细节、敏感日志
- 任何未脱敏的内部资料

## 原始内部资料存放原则
任务书原件保留在共享资料库；本目录发布脱敏版本。执行完成后，K 侧将脱敏报告提交到 `20-reports/K/`，并保持任务编号一致。

## 命名建议
`YYYY-MM-DD_任务编号_主题.md`。状态在正文中标注：`已制定 / 已下发 / 执行中 / 待 C 验收 / 已闭环`（不适用阶段不强加）。
