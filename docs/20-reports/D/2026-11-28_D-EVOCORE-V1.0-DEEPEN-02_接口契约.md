# E 接口契约

延续 /api/ws/autonomy/evocore 前缀、主人会话认证和原策略、目标、审批、拒绝、分享接口。额外字段与状态如下。

- GET / 含 goals、signals、budget、policy，追加 permissions、autoApplyEffective 和目标的 kind、title、permission。旧 autoApply 仍反映保存的历史设置，autoApplyEffective 为 false。
- GET /goals/:id 返回现有目标详情，追加本地复盘的 observation/review 或外部来源的 assessment/freshness。外部摘录正文不返回。
- GET /experience 返回当前主人已完成本地复盘的策略、步骤、观察计数和 reviewedAt。requiresRevalidation 为 true。
- POST /skills/:id 原成果 ID 行为保持。已复盘策略 ID 生成仅能经现有流程启用的 SkillLab DRAFT，清单内容为通用复盘步骤和计数。
- 新状态 reviewed 表示本地复盘已完成。evidence_conflict、evidence_uncertain 表示取证候选不能审批晋升，可调用 reject。E 应按不可审批状态渲染；历史 awaiting_approval、rejected、committing、promoted、failed、erased 等继续有效。
- 权限 automatic_local 允许策略开启且不受运行门禁时自动完成本地复盘。owner_confirmation 表示外部来源由主人明确提供，知识仍要主人审批。prohibited 用于受保护内容、无权限、跨主体和未经授权的副作用拒绝。
- 启用、停止、静默及每日预算继续用 POST /policy。信号和策略都绑定服务端主人身份。真实服务登录和伪造 Cookie 测试记录见定向证据。
