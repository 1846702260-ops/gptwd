# 20-reports/K · K 侧报告

## 用途
存放 **K 侧**开发、研究、测试交付的脱敏报告。

## 责任角色
由 **K 侧**产出。

## 应放内容
- 开发、研究、测试类交付报告
- 报告应区分「已验证事实」与「推测」，并写明：日期、版本/候选、结果、风险、下一步

## 不得放内容
- 源码密钥、令牌、凭据、生产地址与配置
- 完整内部审计原件、敏感日志、私人聊天或长期记忆
- 任何未脱敏的内部资料

## 原始内部资料存放原则
报告原件与交付台账保留在共享资料库；本目录仅发布脱敏结论。涉及工具选型、架构或方案时，只写经过验证的公开事实与判断，不披露内部环境细节。

## 命名建议
`YYYY-MM-DD_任务编号_主题_报告.md`，任务编号与对应 `10-tasks/K/` 任务书一致。
