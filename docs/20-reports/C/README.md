# 20-reports/C · C 侧报告

## 用途
存放 **C 侧**验收、修复、复验的脱敏报告。

## 责任角色
由 **C 侧**产出。

## 应放内容
- 独立验收报告、修复记录、复验结论
- 报告应区分「已验证事实」与「推测」，并写明：日期、版本/候选、结果、风险、下一步

## 不得放内容
- 令牌、密钥、生产地址与配置、内部架构细节
- 完整内部审计原件、敏感日志、私人聊天或长期记忆
- 任何未脱敏的内部资料

## 原始内部资料存放原则
报告原件保留在共享资料库；本目录仅发布脱敏结论。涉及具体验收项时，用任务编号链接到 `10-tasks/C/` 对应任务书，不在公开报告中披露内部证据细节。

## 命名建议
`YYYY-MM-DD_任务编号_主题_报告.md`，任务编号与对应 `10-tasks/C/` 任务书一致。
