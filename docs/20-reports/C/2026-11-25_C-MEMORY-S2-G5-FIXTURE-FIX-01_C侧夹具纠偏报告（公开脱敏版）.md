## 二、三处缺陷与修订

### L02 纠错后按新值

- 缺陷：账本替身 `logTurn` 为空实现，纠错轮不进入下一轮历史；断言要求回答任何位置不得出现旧值字面，把正确的否定式表述判错。
- 修订：替身真实持久化并按会话过滤；断言改为"新值=现在、旧值若出现必须标为历史"，拒绝旧值当现在、两地并存、含糊回避、无新值。
- 对照：正确回答 5/5 通过、负例 6/6 拒绝；原断言对正确回答通过率 0/5。

### L09 跨用户隔离

- 缺陷：种子主体与提问主体共用同一变量，被隔离用户自己的记忆里就有他人隐私，"隔离"逻辑上必败。
- 修订：种子恒写合成主人 A，提问用 B；判据前移到**实际发给模型的请求**，并加 A 的正向控制（能召回）。禁止把"随机未复述"当隔离成功。

### L10 换会话不串档

- 缺陷：种子写入正式长期记忆（无会话维度），换 sessionId 仍读得到，"换会话"实际没换。
- 修订：改用工作会话的会话局部目标（per-session、TTL、不写正式记忆），两个真实不同 sessionId；判据前移到请求；另存一条全局长期事实作反向对照，防止误杀合法跨会话记忆。
