## 本轮修复

**① 正文混入 CSS/JS。** 原 `stripBlocks` 只删**成对闭合**的 `style` 块，两种真实情形会漏：抓取按 400KB 截断时截断点落在标签中间（无闭合标签）；CSS 里写 `content:"</style>"` 让成对正则提前结束。未闭合 `<script>` 同理把 JS 源码带进正文。

改为三层：成对删除 → 删未闭合块（吃到下一个闭合标签或文末）→ 删残余 CSS（规则块/自定义属性/孤立花括号）。**只在还有开标签时动手**，不吃正常页面里开标签之后的正文（已加专项测试 R1-5）。

**② CSS token 触发密钥误判。** 原正则 `(api_key|token|secret)\s*[:=]\s*\S{8,}` 把 `--md-token:rgba(0,0,0,.8)`、`--token:12px` 判成密钥泄漏，真实页面因此被 `untrusted_directive` 整页拦掉。

改为先抓"键名+值"再**按值判定**：CSS 值（颜色/尺寸/函数/关键字）不报；密钥形态（`sk-`/`ghp_`/`xoxb-`/`AKIA`/JWT/高熵长串）照报；裸密钥（无键名）单独扫一遍；强键名配普通词仍需值像密钥。**真密钥防护没有放松**——六类前缀 + 两类高熵逐条测过。
