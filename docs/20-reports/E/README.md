# 20-reports/E · E 侧报告

## 用途
存放 **E 侧**生态适配与扩展研发的脱敏报告。

## 责任角色
由 **E 侧**产出。

## 应放内容
- 外部能力适配、技能与工具接入、非核心功能与界面扩展类交付报告
- 报告应区分「已验证事实」与「推测」，并写明：日期、版本/候选、结果、风险、下一步

## 不得放内容
- 源码密钥、令牌、凭据、生产地址与配置
- 六核核心契约改动、第二套记忆真源或运行中枢相关内容
- 任何未脱敏的内部资料

## 原始内部资料存放原则
报告原件与交付台账保留在共享资料库；本目录仅发布脱敏结论。涉及具体扩展项时，用任务编号链接到 `10-tasks/E/` 对应任务书；不披露内部环境细节，不修改 K 在途任务占用的路径或生产环境。

## 命名建议
`YYYY-MM-DD_任务编号_主题_报告.md`，任务编号与对应 `10-tasks/E/` 任务书一致。
