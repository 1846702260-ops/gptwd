## 做了什么

在现有 Web/PWA 里新增「更多 → 生核」子页（`#/evocore`），把 C 验收候选已落地的生核能力接成可操作界面：

1. **运行状态**：`running / blocked / failures / enabled / stopped` + 四数条（进行中/待批/已晋升/未通过）+ 目标队列。
2. **学习目标与进度**：列表按 `state` 分组；点开按 id 拉 `inspect`，显示结论、来源、证据（读取时间/剩余 24h 有效期/sha256 前 8）、失败原因。
3. **待确认晋升**：进入页面即拉取正文与两条来源，**看不到正文不给批准**；拒绝/批准均二次点击；服务端 409/503 如实回显。
4. **控制**：总开关 / 暂停（保留开关）/ 恢复（清零熔断计数）/ 停止（连开关一起关），全部落 `policy`。
5. **预算与静默**：今日 `used/dailyReads` + 进度条；预算与静默时间可改并保存（前端先校验，服务端再校验）。
6. **成果与证据**：`promoted` 条目经 `share` 回取结论 + 两条来源。
7. **技能候选**：由已晋升目标生成（DRAFT），可拒绝。
8. **异常与恢复**：8 类门禁原因逐条给「为什么 + 怎么恢复」；信号与失败条目可追溯。

底栏仍是「总览 / 聊天球 / 更多」三键，未新增主导航；复用 `PageHead` 与既有卡片/按钮样式，无新依赖。
