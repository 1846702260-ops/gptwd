# 09 · 敏感操作弹层溢出裁切修复 + 密码显隐

反馈 2026-11-26 23:08｜上线 2026-11-26 23:12｜坐标 `ada78e7`

## 1. 现象

输入当前密码、点「修改」后，重验证卡片**整体左移出屏**：标题被裁成「作：重新验证」，左侧文字与「确认」按钮看不到，右侧圆角也超出屏幕。功能本身可提交，但界面不可用。

## 2. 根因

上一版把弹层从「页面末尾的普通卡片」改成 `position: fixed` 浮层，但**仍渲染在 `SecurityCenter` 的 `<section>` 内**：

1. `fixed` 元素的包含块并非视口——祖先链上存在会创建包含块的容器（transform / filter / backdrop-filter / contain 一类），浮层被约束在内容区而非视口。
2. 面板宽度按「容器宽度」计算（`width:100% + maxWidth`），在 390px 窄屏下叠加该容器的偏移，最终左边缘为负、右侧越界，被 `html,body{overflow-x:hidden}` 裁掉。
3. 由于裁切发生在视口外，页面不会出现横向滚动条，用户只能看到「卡片显示不正常」。

项目内已有正确范式：`CenterSheet` 用 `createPortal` + `.csheet-mask`（`position:fixed; inset:0; z-index:200`）+ `.csheet { width: min(560px, 100%) }`。本次即对齐该写法。

## 3. 修复

| # | 改动 | 说明 |
| --- | --- | --- |
| 1 | 两个弹层（重新验证 / 确认撤销）改用 `createPortal(..., document.body)` | 挂到 body，彻底脱离页面容器与祖先包含块 |
| 2 | 面板宽度改 `width: min(460px, 100%)`，去 `maxWidth`，加 `box-sizing: border-box` 与 `margin: auto` | 与 `.csheet` 一致，窄屏按可用宽度收缩 |
| 3 | 遮罩用 `left/top/width/height 100%` + `overscroll-behavior: contain` | 不依赖 `inset` 简写在旧内核的表现 |
| 4 | 弹层打开时锁 `body.overflow = hidden` | 背景不再跟着滚动（iOS 尤其明显） |
| 5 | 去掉重验证密码框的 `autoFocus` | 避免 iOS 键盘弹起瞬间推动视口，造成浮层"跳一下" |

## 4. 新增：密码显示 / 隐藏

新增组件内 `PwInput`，用于「新密码」与「当前密码」两个输入框：

- 输入框右侧固定一个文字按钮，默认「显示」，点击切换为「隐藏」，`type` 在 `password` / `text` 间切换
- `type="button"`，不会误触发表单提交；带 `aria-label` 与 `aria-pressed`
- 输入框 `padding-right: 58px`，文字不会压到按钮；按钮绝对定位、垂直居中
- 关掉 `autoCapitalize` / `autoCorrect` / `spellCheck`，避免手机输入法改写密码

## 5. 同类问题排查结论

| 组件 | 实现方式 | 结论 |
| --- | --- | --- |
| `SecurityCenter` 两个弹层 | 内联卡片 + fixed（上一版） | **有问题，本次已修** |
| `CenterSheet` | `createPortal` + `.csheet-mask` + `width:min()` | 范式正确，无需改 |
| `PlatformCard` / `ModelPicker` / `PermPicker` / `SwipeDrawer` / `PluginsPage` / `ApiPage` / `Lightbox` | 均用 CSS 类浮层，不参与页面文档流 | 无同类问题 |
| `KbDebug` | 调试面板，`position:fixed` | 非用户可见功能，未改 |

全仓内联 `position:'fixed'` 仅 `KbDebug` 一处，其余均走 CSS 类。
