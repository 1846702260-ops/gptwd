# 20-reports/Z · Z 侧报告

## 用途
存放 **Z 侧**生产验证与运维的脱敏报告。

## 责任角色
由 **Z 侧**产出。

## 应放内容
- 生产环境验证、运维记录的脱敏摘要
- 报告应区分「已验证事实」与「推测」，并写明：日期、版本/候选、结果、风险、下一步

## 不得放内容
- 生产地址、生产配置、内部架构细节、可利用的漏洞详情
- 令牌、密钥、密码、凭据、敏感日志
- 任何未脱敏的内部资料或私人记忆

## 原始内部资料存放原则
生产验证与运维原件保留在共享资料库；本目录仅发布脱敏后的结论性摘要，不披露可定位生产环境的信息。任务编号与对应 `10-tasks/Z/` 任务书保持一致。

## 命名建议
`YYYY-MM-DD_任务编号_主题_报告.md`。
