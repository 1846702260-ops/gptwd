## 7. 发现的偏差（如实登记，均不阻断 M2 结论）

| # | 偏差 | 性质 | 建议 |
|---|---|---|---|
| 1 | **回执 `remote.count=2` 语义错位**：计数逻辑为 `nas_ls "plain"` 内 `grep zyagi-*.tar.gz`，统计的是**单包旧通道**的 2 个历史包；而 `remote.path` 指向**分片通道**。分片通道下应统计 `plain-shards/` 下快照目录数 | C 类（语义瑕疵，不影响 `verified` 判定，验证由 SHA 闭合） | 建议 C 侧后续修正计数口径；本轮不擅改候选 |
| 2 | **远端分片目录无保留策略**：脚本仅清理本地 `OUT`（7 天），远端 `plain-shards/` 只增不删，每份约 34MB | C 类（容量技术债） | 建议后续独立任务处理，本轮不扩范围 |
| 3 | **`witness` 项缺失**：`backup-spec` 中有 `witness`（默认 `[见证目录]`），但源机上该目录不存在，故未入包（dry-run `missing=2` 之一） | C 类（源侧本无该目录，非备份漏项） | 若需要外部见证，应先建目录并纳入常规运行 |
| 4 | 本地 `plain/` 与 `plain-shards/` 双通道并存 | C 类（过渡态） | 迁移稳定后再议收敛，本轮保留旧包不动 |
