# 六核协同与持续自主成长闭环前置研究（公开脱敏版）

- 任务：R-SIXCORE-COEVOLUTION-M0-01｜日期：2026-11-28｜性质：外部研究 + 隔离 PoC
- 脱敏说明：移除内部协同仓坐标、任务派发流程、凭据与侧别治理细节；仅保留可公开的技术结论与来源。

## 摘要

研究面向六核（规划/执行/评估/学习/沉淀/身份）如何从独立模块发展为统一持续运行的个人智能系统。核心问题之一是：如何验证系统真正获得能力提升，而非仅仅增加功能模块或生成成长记录。

## 核心结论

1. **生成成长记录不等于能力提升。** 隔离实验中，两套机制生成完全相同数量（23 条）的成长记录，但一套把经验锚定到真实执行回执并复用，真实任务成功率由 25%→75%→100%；另一套只采信自述，成功率恒定 25%。差异唯一来源是回执锚定与复用。
2. **防伪治理是闭环可信的前提。** 对无回执自述、伪造回执、身份改写三类伪成长，锚定方案全部拦截、错误吸收为 0；朴素方案全部采信并被污染。
3. **成熟底座已足够，无需另建系统。** 编排层（LangGraph、CrewAI、Google ADK、AgentScope）与记忆/经验层（Mem0、Zep/Graphiti、Letta、ReMe）均为活跃开源项目，可借鉴其事件/状态/经验机制。
4. **建议补"薄契约层"**：统一事件、状态、证据、反馈四类契约，叠加在现有能力之上；不引入第二套认知中枢、长期记忆、任务运行时或学习系统。

## 能力提升验证的四条判据

1. 能力声明必须有真实执行回执锚定（无回执=未验证）；
2. 在固定/滚动任务集上成功率曲线上升，仅记录增长不算；
3. 对无回执、伪造、身份改写注入具备抗污染能力；
4. 外部自报性能须独立复现，跨任务迁移须单独证明。

## 边界

隔离实验为确定性模拟，证明机制相对差异，非真实模型或真实任务的绝对能力值。不涉及生产系统变更，不宣称意识，不把拟人化表达当真实状态。
