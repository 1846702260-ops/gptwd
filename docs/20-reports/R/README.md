# 20-reports/R · R 侧报告

## 用途
存放 **R 侧**技术调研、对照实验与采纳建议的脱敏报告。

## 责任角色
由 **R 侧**产出。

## 应放内容
- 技术调研、源码协议分析、对照实验、可复现 PoC 与候选方案采纳建议报告
- 报告应区分「已验证事实」与「推测」，并写明：日期、版本/候选、结果、风险、下一步

## 不得放内容
- 未经审查的第三方代码、可执行实验细节
- 令牌、密钥、凭据、生产地址与配置、真实账号与记忆
- 任何未脱敏的内部资料

## 原始内部资料存放原则
报告原件与实验底稿保留在共享资料库；本目录仅发布脱敏结论。研究产物不等于正式功能交付，结论交 ChatGPT 裁决；涉及工具选型、架构或方案时，只写经过验证的公开事实与判断，不披露内部环境细节。

## 命名建议
`YYYY-MM-DD_任务编号_主题_报告.md`，任务编号与对应 `10-tasks/R/` 任务书一致。
