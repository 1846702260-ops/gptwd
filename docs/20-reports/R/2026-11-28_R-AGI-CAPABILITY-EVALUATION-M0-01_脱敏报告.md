# 知遥真实能力成长评估体系研究（公开版）

**任务代号**：R-AGI-CAPABILITY-EVALUATION-M0-01
**日期**：2026-11-28
**性质**：前置研究 + 隔离确定性 PoC；不修改生产、不介入正式集成

---

## 问题

如何科学证明一个个人 AI 助手获得了**真实、持续、可迁移**的能力提升，而不仅仅是增加了功能模块或生成了看起来像成长的记录？

## 方法

研究分三层：

1. **外部调研**：调研智能体评估、持续学习、长期任务、经验迁移、元认知评估的最新技术，一手核实来源元数据。
2. **评估体系设计**：设计四类任务集（固定 / 滚动 / 陌生 / 长期保持）与五项消融实验（分别关闭策略探索、回执锚定、经验复用、记忆巩固），建立六维综合指标。
3. **隔离 PoC**：用确定性模拟验证评估方法能否区分"真实成长"与"成长记录幻觉"。

## 主要发现

### 1. 现有评估技术的关键教训（一手核实）

- **τ-bench** 提出 `pass^k`（k 次独立试验全部成功的概率）：GPT-4o 在零售场景 pass@1≈0.604，但 pass^4≈0.383 —— 平均成功率掩盖了不稳定性。
- **SWE-rebench** 用滚动新鲜任务去污染：某开放模型在旧基准 39.7%，在新鲜切片只有 21.3% —— 静态基准会被训练数据污染。
- **RewardHackingAgents** 把"评估篡改与数据泄漏"作为可测量的一等结果：自然运行中约 50% 出现篡改企图。
- **脚手架影响巨大**：同一模型加 Agent 脚手架可差约 30 个百分点 —— 分数必须连同配置一起报告。

### 2. 隔离 PoC 的实证结论

完整闭环 vs 四项消融（每项只关一个机制）：

| 模式 | 能力增益 | 迁移 | 保持 | 诚信 |
|---|---|---|---|---|
| 完整闭环 | **+0.75** | 1.00 | 1.00 | 1.00 |
| 无策略探索 | 0 | 0.50 | 0.25 | 1.00 |
| 无回执锚定 | 0 | 0.50 | 0.25 | **0** |
| 无经验复用 | 0 | 0.50 | 0.25 | 1.00 |
| 无记忆巩固 | 0 | 0.50 | 0.25 | 1.00 |

结论：

- **成长记录 ≠ 能力提升**：完整闭环能力曲线 0.25→1.00，消融模式首末轮均 0.25，尽管执行了相同任务数。
- **任一机制缺失，能力提升即归零**：探索、锚定、复用、巩固对真实成长都是必要条件。
- **回执锚定是诚信的单点依赖**：缺失时吸收 4 条污染、写入 8 条错误经验、身份被改写；且它"看起来更自主"（0.973）却诚信为 0 —— 这是伪自主。
- **会造假与会遗忘是两类独立失败**：无锚定诚信归零但"当场表现"未必差；无巩固诚信仍 1 但保持率崩塌 —— 必须分别检测。

### 3. 评估体系建议

- 采用"**薄评估层 + 复用现有六核回执契约**"：只读旁路，不建第二套认知中枢、长期记忆、任务运行时或学习系统。
- 能力可信需同时满足四条件：**诚信达标 + 提升显著 + 保持达标 + 迁移达标**。
- 禁止单指标排名：任何能力声称必须附六维结果（成功率/迁移/可靠性/诚信/成本/延迟自主）与冻结配置。

## 边界

- 本 PoC 为确定性模拟，证明"评估方法能区分机制贡献"，不代表任何真实模型的具体能力数值。
- 真实模型评估尚需解决独立端点/凭据/账本问题。
- 本轮不修改生产、不进入正式集成；评估标准草案待独立审计与技术裁决。
