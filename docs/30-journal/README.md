# 30-journal · 知遥记录（脱敏摘要）

## 用途
存放《知遥记录》的**公开脱敏摘要**，用于对外呈现项目进展脉络。

## 责任角色
由 **C 侧**维护。

## 应放内容
- 《知遥记录》的脱敏摘要：阶段性进展、关键节点、验收结论摘要
- 每次记录应简洁，注明日期与对应任务编号

## 不得放内容
- 完整的内部原始成长记录（**严禁上传公开仓库**）
- 用户私人聊天、长期记忆、个人身份信息
- 令牌、密钥、生产地址与配置、敏感日志

## 原始内部资料存放原则
完整《知遥记录》原件始终保留在既有共享资料库。本目录只放经过脱敏、可公开的摘要片段；如无法确认是否脱敏，宁可不放。本目录不构成自动记录或自动派工机制。

## 命名建议
`YYYY-MM-DD_知遥记录_主题摘要.md`。
