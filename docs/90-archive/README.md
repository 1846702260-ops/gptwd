# 90-archive · 归档索引

## 用途
存放已闭环任务与报告的归档索引，便于对外追溯历史脉络。

## 责任角色
由 **ChatGPT** 维护。

## 应放内容
- 已闭环任务与报告的索引（任务编号、标题、日期、状态）
- 指向 `10-tasks/` 与 `20-reports/` 中对应文件的链接
- 归档说明与脱敏摘要

## 不得放内容
- 未脱敏的历史任务书或报告原件
- 令牌、密钥、生产地址与内部架构细节
- 敏感日志、私人记忆、内部原件

## 原始内部资料存放原则
归档原件保留在共享资料库；本目录只放索引与脱敏摘要，不搬运历史内部资料到公开仓库。不得因为某历史文件已存在于仓库中就默认其已通过保密审查。

## 命名建议
`YYYY-MM-DD_归档索引_主题.md`，或按周期维护单一索引文件。
