# 50-releases · 版本与发布状态

## 用途
存放版本状态、发布门禁和决策摘要，对外呈现知遥 AGI 的发布脉络。

## 责任角色
由 **ChatGPT 汇总**，**C / Z 核验**。

## 应放内容
- 公开版本号与状态摘要
- 发布门禁条件与决策摘要
- 版本变更的可公开说明

## 不得放内容
- 生产部署地址、生产配置、内部版本号映射细节
- 令牌、密钥、凭据、内部架构细节
- 未脱敏的内部发布记录或敏感日志

## 原始内部资料存放原则
内部版本与发布记录保留在共享资料库；本目录仅发布脱敏后的状态与决策摘要。本目录是信息展示，不构成自动部署或发布触发机制。

## 命名建议
`YYYY-MM-DD_版本状态_主题.md`。
