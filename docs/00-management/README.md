# 00-management · 管理总纲

## 用途
存放知遥 AGI 的公开脱敏管理材料：总纲、阶段计划、优先级、任务索引与决策记录。

## 责任角色
由 **ChatGPT 总协调**维护。

## 应放内容
- 公开版总体框架与阶段计划
- 优先级与任务索引（指向 `10-tasks/` 各任务书）
- 决策记录的脱敏摘要
- 面向公众的项目说明与协作约定

## 不得放内容
- 内部路线图原文、未脱敏决策记录
- 令牌、密钥、生产地址、内部架构细节
- 私人记忆或敏感日志

## 原始内部资料存放原则
内部管理原件保留在 K/C/Z/R/E 五侧共享资料库；本目录仅发布经过脱敏、可公开的表述。涉及具体任务时，用任务编号链接到 `10-tasks/` 对应任务书。

## 命名建议
`YYYY-MM-DD_主题.md`，例如阶段计划、任务索引、决策摘要。
